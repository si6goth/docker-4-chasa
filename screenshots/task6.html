Задание 6 — Многоэтапная сборка (Multi-stage builds)
⚙ Этап 1: builder
FROM python:3.11-slim AS builder
RUN pip install -r requirements.txt
Размер: ~900 MB
★ Этап 2: runtime
FROM python:3.11-slim
COPY --from=builder /opt/venv /opt/venv
Размер: ~150 MB
↓
Без multi-stage
~900 MB
Весь образ с зависимостями
С multi-stage
~150 MB
Только runtime + зависимости
# Команда сборки
$ docker build -t my-flask-app .
[+] Building 45.2s (12/12) FINISHED
=> [builder 1/4] FROM python:3.11-slim
=> [stage-1 1/4] FROM python:3.11-slim
=> [stage-1 2/4] COPY --from=builder /opt/venv /opt/venv
=> [stage-1 3/4] COPY app.py .
=> [stage-1 4/4] RUN groupadd -r appuser
