Задание 4 — Постоянное хранение данных (Volumes)
📁 Named Volume: postgres_data
↓
/var/lib/postgresql/data (в контейнере)
Данные сохраняются между перезапусками контейнеров
📁 Bind Mount: ./app.py
↓
/app/app.py (в контейнере)
Изменения в коде применяются без пересборки образа
# Остановка и удаление контейнеров
$ docker compose down
[+] Running 3/3
▮ Container pgadmin Removed
▮ Container flask-web Removed
▮ Container postgres-db Removed
# Повторный запуск — данные PostgreSQL сохранены!
$ docker compose up -d
[+] Running 3/3
▮ Container postgres-db Started
▮ Container flask-web Started
▮ Container pgadmin Started
# Создание тома вручную
$ docker volume create my_custom_volume
