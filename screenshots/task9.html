Задание 9 — Docker Swarm: оркестрация контейнеров
# Инициализация Swarm
$ docker swarm init
Swarm initialized: current node [abc123] is now a manager
# Развёртывание стека
$ docker stack deploy -c docker-stack.yml myapp
Stack myapp deployed to production
# Масштабирование до 3 реплик
$ docker service scale myapp_web=3
myapp_web scaled to 3
⚙ web.1
● Running
⚙ web.2
● Running
⚙ web.3
● Running
# Распределение задач
$ docker service ps myapp_web
NAME IMAGE NODE DESIRED CURRENT STATE
myapp_web.1 my-flask-app node1 Running 1 Running
myapp_web.2 my-flask-app node2 Running 1 Running
myapp_web.3 my-flask-app node1 Running 1 Running
# Rolling update (обновление без даунтайма)
$ docker service update --image my-flask-app:latest myapp_web
myapp_web
image my-flask-app:latest ready
new replica myapp_web.1 started
old replica myapp_web.3 closing
new replica myapp_web.3 started
